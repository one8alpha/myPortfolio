# Mayur Vitekar - Personal Portfolio

Personal developer portfolio website showcasing my projects, technical skills, and experience. Built with HTML, CSS, JavaScript, and Vite.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Tooling**: [Vite](https://vitejs.dev/)

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
